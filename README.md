# Global Auto News

국가별 완성차 업체 뉴스 대시보드입니다. 뉴스 수집 후보를 Google News와 Bing News RSS에서 모아 게시일과 중복을 정리하고, 업체별 기사로 표시합니다.

## 공개 페이지

- 대시보드: `https://aneta0623-bot.github.io/global-auto-news/`
- 파일명 주소: `https://aneta0623-bot.github.io/global-auto-news/global-auto-news.html`
- 업체 대시보드 전용 보기: `https://aneta0623-bot.github.io/global-auto-news/global-auto-news-01.html`

## 자동 갱신

GitHub Actions가 매주 일요일 14:00 한국시간에 `refresh-news.js`를 실행하고, 갱신된 기사 데이터와 대시보드를 GitHub Pages에 배포합니다. 필요하면 Actions 탭에서 `Refresh news and publish dashboard`를 수동 실행할 수도 있습니다.

검색 피드의 기사는 원문 전문 확인 전의 검색 후보입니다. 기사 내용과 사실관계는 각 발행사의 원문에서 확인해야 합니다.
